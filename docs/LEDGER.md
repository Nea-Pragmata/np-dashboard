## Tooling — PocketBase types

- PB collection types are GENERATED, not hand-written. Run `bun run typegen` (wrapper `scripts/typegen.mjs` → `pocketbase-typegen`) to (re)write `src/lib/pocketbase-types.ts`. Reads `POCKETBASE_URL`/`POCKETBASE_ADMIN_EMAIL`/`POCKETBASE_ADMIN_PASSWORD` from `.env` (gitignored). `.env.example` documents the vars.
- **Rule for all build agents:** after ANY schema change (fields/collections), re-run `bun run typegen` and import types from `$lib/pocketbase-types` — never hand-author collection record types. App reads `PUBLIC_PB_URL` (add to `.env`, milestone 2).
